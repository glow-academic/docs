# `glow admin licenses update`

Update an existing license

## Usage

```bash
glow admin licenses update id <id> [--key] [--expiry] [--active]
```

## Options

| Flag | Required | Description |
|---|---|---|
| `id` | Yes | License ID |
| `--key` | No | — |
| `--expiry` | No | — |
| `--active` | No | — |
