# `POST` `/cohorts/drafts`

Get Cohort Drafts

List cohort drafts owned by the current profile.

## Response (`GetCohortDraftsApiResponse`)

| Field | Type | Required | Description |
|---|---|---|---|
| `entries` | [`GetCohortDraftResponse`](/api-reference/cohorts/types#getcohortdraftresponse)[] | No | List of cohort draft entries |
