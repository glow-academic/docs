# `POST` `/evals/drafts`

Get Eval Drafts

List eval drafts owned by the current profile.

## Response (`GetEvalDraftsApiResponse`)

| Field | Type | Required | Description |
|---|---|---|---|
| `entries` | [`GetEvalDraftResponse`](/api-reference/evals/types#getevaldraftresponse)[] | No | List of eval draft entries |
