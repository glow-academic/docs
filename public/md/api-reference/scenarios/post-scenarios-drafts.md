# `POST` `/scenarios/drafts`

Get Scenario Drafts

List scenario drafts owned by the current profile.

## Response (`GetScenarioDraftsApiResponse`)

| Field | Type | Required | Description |
|---|---|---|---|
| `entries` | [`GetScenarioDraftResponse`](/api-reference/scenarios/types#getscenariodraftresponse)[] | No | List of scenario draft entries |
