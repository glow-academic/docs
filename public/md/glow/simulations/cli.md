# Simulations

## Commands

### `glow simulations`

```bash
glow simulations <action> [--body JSON]
```

### `glow simulations search`

```bash
glow simulations search
```

### `glow simulations get`

```bash
glow simulations get --body '\{"simulation_id": "..."}'
```

### `glow simulations create`

```bash
glow simulations create --body '\{...}'
```

### `glow simulations update`

```bash
glow simulations update --body '\{"simulation_id": "...", ...}'
```

### `glow simulations delete`

```bash
glow simulations delete --body '\{"simulation_id": "..."}'
```

### `glow simulations list`

```bash
glow simulations list
```

### `glow simulations export`

```bash
glow simulations export
```

### `glow simulations draft`

```bash
glow simulations draft --body '\{...}'
```

### `glow simulations media`

```bash
glow simulations <file|image|text|audio|video> <upload|download|create|chunk|status|finalize|discover|preview> [flags]
```
