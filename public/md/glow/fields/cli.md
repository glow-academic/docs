# Fields

## Commands

### `glow fields`

```bash
glow fields <action> [--body JSON]
```

### `glow fields search`

```bash
glow fields search
```

### `glow fields get`

```bash
glow fields get --body '\{"field_id": "..."}'
```

### `glow fields create`

```bash
glow fields create --body '\{...}'
```

### `glow fields update`

```bash
glow fields update --body '\{"field_id": "...", ...}'
```

### `glow fields delete`

```bash
glow fields delete --body '\{"field_id": "..."}'
```

### `glow fields list`

```bash
glow fields list
```

### `glow fields export`

```bash
glow fields export
```

### `glow fields draft`

```bash
glow fields draft --body '\{...}'
```

### `glow fields media`

```bash
glow fields <file|image|text|audio|video> <upload|download|create|chunk|status|finalize|discover|preview> [flags]
```
