# Pricing

## Commands

### `glow pricing`

```bash
glow pricing <action> [--body JSON]
```

### `glow pricing search`

```bash
glow pricing search
```

### `glow pricing get`

```bash
glow pricing get --body '\{"pricing_id": "..."}'
```

### `glow pricing create`

```bash
glow pricing create --body '\{...}'
```

### `glow pricing update`

```bash
glow pricing update --body '\{"pricing_id": "...", ...}'
```

### `glow pricing delete`

```bash
glow pricing delete --body '\{"pricing_id": "..."}'
```

### `glow pricing list`

```bash
glow pricing list
```

### `glow pricing export`

```bash
glow pricing export
```

### `glow pricing draft`

```bash
glow pricing draft --body '\{...}'
```

### `glow pricing media`

```bash
glow pricing <file|image|text|audio|video> <upload|download|create|chunk|status|finalize|discover|preview> [flags]
```
