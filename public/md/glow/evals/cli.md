# Evals

## Commands

### `glow evals`

```bash
glow evals <action> [--body JSON]
```

### `glow evals search`

```bash
glow evals search
```

### `glow evals get`

```bash
glow evals get --body '\{"eval_id": "..."}'
```

### `glow evals create`

```bash
glow evals create --body '\{...}'
```

### `glow evals update`

```bash
glow evals update --body '\{"eval_id": "...", ...}'
```

### `glow evals delete`

```bash
glow evals delete --body '\{"eval_id": "..."}'
```

### `glow evals list`

```bash
glow evals list
```

### `glow evals export`

```bash
glow evals export
```

### `glow evals draft`

```bash
glow evals draft --body '\{...}'
```

### `glow evals media`

```bash
glow evals <file|image|text|audio|video> <upload|download|create|chunk|status|finalize|discover|preview> [flags]
```
