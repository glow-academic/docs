# Cohorts

## Commands

### `glow cohorts`

```bash
glow cohorts <action> [--body JSON]
```

### `glow cohorts search`

```bash
glow cohorts search
```

### `glow cohorts get`

```bash
glow cohorts get --body '\{"cohort_id": "..."}'
```

### `glow cohorts create`

```bash
glow cohorts create --body '\{...}'
```

### `glow cohorts update`

```bash
glow cohorts update --body '\{"cohort_id": "...", ...}'
```

### `glow cohorts delete`

```bash
glow cohorts delete --body '\{"cohort_id": "..."}'
```

### `glow cohorts list`

```bash
glow cohorts list
```

### `glow cohorts export`

```bash
glow cohorts export
```

### `glow cohorts draft`

```bash
glow cohorts draft --body '\{...}'
```

### `glow cohorts media`

```bash
glow cohorts <file|image|text|audio|video> <upload|download|create|chunk|status|finalize|discover|preview> [flags]
```
