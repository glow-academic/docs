# Group

## Commands

### `glow group`

```bash
glow group <action> [--body JSON]
```

### `glow group search`

```bash
glow group search
```

### `glow group get`

```bash
glow group get --body '\{"group_id": "..."}'
```

### `glow group create`

```bash
glow group create --body '\{...}'
```

### `glow group update`

```bash
glow group update --body '\{"group_id": "...", ...}'
```

### `glow group delete`

```bash
glow group delete --body '\{"group_id": "..."}'
```

### `glow group list`

```bash
glow group list
```

### `glow group export`

```bash
glow group export
```

### `glow group draft`

```bash
glow group draft --body '\{...}'
```

### `glow group media`

```bash
glow group <file|image|text|audio|video> <upload|download|create|chunk|status|finalize|discover|preview> [flags]
```
