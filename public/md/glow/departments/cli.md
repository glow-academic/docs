# Departments

## Commands

### `glow departments`

```bash
glow departments <action> [--body JSON]
```

### `glow departments search`

```bash
glow departments search
```

### `glow departments get`

```bash
glow departments get --body '\{"department_id": "..."}'
```

### `glow departments create`

```bash
glow departments create --body '\{...}'
```

### `glow departments update`

```bash
glow departments update --body '\{"department_id": "...", ...}'
```

### `glow departments delete`

```bash
glow departments delete --body '\{"department_id": "..."}'
```

### `glow departments list`

```bash
glow departments list
```

### `glow departments export`

```bash
glow departments export
```

### `glow departments draft`

```bash
glow departments draft --body '\{...}'
```

### `glow departments media`

```bash
glow departments <file|image|text|audio|video> <upload|download|create|chunk|status|finalize|discover|preview> [flags]
```
