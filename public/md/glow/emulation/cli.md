# Emulation

## Commands

### `glow emulate`

Emulate another user profile

```bash
glow emulate
```

| Flag | Required | Description |
|---|---|---|
| `target_profile_id` | Yes | Target profile ID to emulate |
| `--ttl` | No | TTL in seconds |

### `glow unemulate`

Stop emulating and return to your own profile

```bash
glow unemulate
```
