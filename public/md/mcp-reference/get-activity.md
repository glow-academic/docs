# `get_activity`

get activity

## Parameters

| Name | Type | Required | Description |
|---|---|---|---|
| `date_from` | `string` | No | Filter start date |
| `date_to` | `string` | No | Filter end date |
| `department_ids` | `array` | No | Department IDs to filter by |
| `roles` | `array` | No | Roles to filter by |

## Example

```json
{
  "name": "get_activity",
  "arguments": {}
}
```
