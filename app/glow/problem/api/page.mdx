# Problem

## Endpoints

### `POST` `/problem`

Create Problem

Create new problem entry.

**Request body** (`CreateProblemRequest`):

| Field | Type | Required | Description |
|---|---|---|---|
| `type` | `string` | Yes | — |
| `message` | `string` | Yes | — |

**Response** (`CreateProblemResponse`):

| Field | Type | Required | Description |
|---|---|---|---|
| `problem_id` | `string` | Yes | — |
| `success` | `boolean` | Yes | — |
| `message` | `string` | Yes | — |
