# Agents

## Commands

### `glow agents`

```bash
glow agents <action> [--body JSON]
```

### `glow agents search`

```bash
glow agents search
```

### `glow agents get`

```bash
glow agents get --body '\{"agent_id": "..."}'
```

### `glow agents create`

```bash
glow agents create --body '\{...}'
```

### `glow agents update`

```bash
glow agents update --body '\{"agent_id": "...", ...}'
```

### `glow agents delete`

```bash
glow agents delete --body '\{"agent_id": "..."}'
```

### `glow agents list`

```bash
glow agents list
```

### `glow agents export`

```bash
glow agents export
```

### `glow agents draft`

```bash
glow agents draft --body '\{...}'
```

### `glow agents media`

```bash
glow agents <file|image|text|audio|video> <upload|download|create|chunk|status|finalize|discover|preview> [flags]
```
