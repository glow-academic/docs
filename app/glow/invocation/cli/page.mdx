# Invocation

## Commands

### `glow invocation`

```bash
glow invocation <action> [--body JSON]
```

### `glow invocation search`

```bash
glow invocation search
```

### `glow invocation get`

```bash
glow invocation get --body '\{"invocation_id": "..."}'
```

### `glow invocation create`

```bash
glow invocation create --body '\{...}'
```

### `glow invocation update`

```bash
glow invocation update --body '\{"invocation_id": "...", ...}'
```

### `glow invocation delete`

```bash
glow invocation delete --body '\{"invocation_id": "..."}'
```

### `glow invocation list`

```bash
glow invocation list
```

### `glow invocation export`

```bash
glow invocation export
```

### `glow invocation draft`

```bash
glow invocation draft --body '\{...}'
```

### `glow invocation media`

```bash
glow invocation <file|image|text|audio|video> <upload|download|create|chunk|status|finalize|discover|preview> [flags]
```
