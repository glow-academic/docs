# Leaderboard

## Commands

### `glow leaderboard`

```bash
glow leaderboard <action> [--body JSON]
```

### `glow leaderboard search`

```bash
glow leaderboard search
```

### `glow leaderboard get`

```bash
glow leaderboard get --body '\{"leaderboard_id": "..."}'
```

### `glow leaderboard create`

```bash
glow leaderboard create --body '\{...}'
```

### `glow leaderboard update`

```bash
glow leaderboard update --body '\{"leaderboard_id": "...", ...}'
```

### `glow leaderboard delete`

```bash
glow leaderboard delete --body '\{"leaderboard_id": "..."}'
```

### `glow leaderboard list`

```bash
glow leaderboard list
```

### `glow leaderboard export`

```bash
glow leaderboard export
```

### `glow leaderboard draft`

```bash
glow leaderboard draft --body '\{...}'
```

### `glow leaderboard media`

```bash
glow leaderboard <file|image|text|audio|video> <upload|download|create|chunk|status|finalize|discover|preview> [flags]
```
