# Documents

## Commands

### `glow documents`

```bash
glow documents <action> [--body JSON]
```

### `glow documents search`

```bash
glow documents search
```

### `glow documents get`

```bash
glow documents get --body '\{"document_id": "..."}'
```

### `glow documents create`

```bash
glow documents create --body '\{...}'
```

### `glow documents update`

```bash
glow documents update --body '\{"document_id": "...", ...}'
```

### `glow documents delete`

```bash
glow documents delete --body '\{"document_id": "..."}'
```

### `glow documents list`

```bash
glow documents list
```

### `glow documents export`

```bash
glow documents export
```

### `glow documents draft`

```bash
glow documents draft --body '\{...}'
```

### `glow documents media`

```bash
glow documents <file|image|text|audio|video> <upload|download|create|chunk|status|finalize|discover|preview> [flags]
```
