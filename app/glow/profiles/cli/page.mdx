# Profiles

## Commands

### `glow profiles`

```bash
glow profiles <action> [--body JSON]
```

### `glow profiles search`

```bash
glow profiles search
```

### `glow profiles get`

```bash
glow profiles get --body '\{"profile_id": "..."}'
```

### `glow profiles create`

```bash
glow profiles create --body '\{...}'
```

### `glow profiles update`

```bash
glow profiles update --body '\{"profile_id": "...", ...}'
```

### `glow profiles delete`

```bash
glow profiles delete --body '\{"profile_id": "..."}'
```

### `glow profiles list`

```bash
glow profiles list
```

### `glow profiles export`

```bash
glow profiles export
```

### `glow profiles draft`

```bash
glow profiles draft --body '\{...}'
```

### `glow profiles media`

```bash
glow profiles <file|image|text|audio|video> <upload|download|create|chunk|status|finalize|discover|preview> [flags]
```
