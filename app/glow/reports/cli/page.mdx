# Reports

## Commands

### `glow reports`

```bash
glow reports <action> [--body JSON]
```

### `glow reports search`

```bash
glow reports search
```

### `glow reports get`

```bash
glow reports get --body '\{"report_id": "..."}'
```

### `glow reports create`

```bash
glow reports create --body '\{...}'
```

### `glow reports update`

```bash
glow reports update --body '\{"report_id": "...", ...}'
```

### `glow reports delete`

```bash
glow reports delete --body '\{"report_id": "..."}'
```

### `glow reports list`

```bash
glow reports list
```

### `glow reports export`

```bash
glow reports export
```

### `glow reports draft`

```bash
glow reports draft --body '\{...}'
```

### `glow reports media`

```bash
glow reports <file|image|text|audio|video> <upload|download|create|chunk|status|finalize|discover|preview> [flags]
```
