# Connect

## Endpoints

### `POST` `/connect`

Connect

Create a stream session for the authenticated profile.

**Response** (`ConnectResponse`):

| Field | Type | Required | Description |
|---|---|---|---|
| `sid` | `string` | Yes | — |

---

### `POST` `/disconnect`

Disconnect

Destroy a stream session.

**Request body** (`DisconnectRequest`):

| Field | Type | Required | Description |
|---|---|---|---|
| `sid` | `string` | Yes | — |

**Response** (`DisconnectResponse`):

| Field | Type | Required | Description |
|---|---|---|---|
| `success` | `boolean` | Yes | — |

---
