# Home

## Commands

### `glow home`

```bash
glow home <action> [--body JSON]
```

### `glow home search`

```bash
glow home search
```

### `glow home get`

```bash
glow home get --body '\{"home_id": "..."}'
```

### `glow home create`

```bash
glow home create --body '\{...}'
```

### `glow home update`

```bash
glow home update --body '\{"home_id": "...", ...}'
```

### `glow home delete`

```bash
glow home delete --body '\{"home_id": "..."}'
```

### `glow home list`

```bash
glow home list
```

### `glow home export`

```bash
glow home export
```

### `glow home draft`

```bash
glow home draft --body '\{...}'
```

### `glow home media`

```bash
glow home <file|image|text|audio|video> <upload|download|create|chunk|status|finalize|discover|preview> [flags]
```
