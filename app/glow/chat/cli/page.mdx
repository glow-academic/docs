# Chat

## Commands

### `glow chat`

```bash
glow chat <action> [--body JSON]
```

### `glow chat search`

```bash
glow chat search
```

### `glow chat get`

```bash
glow chat get --body '\{"chat_id": "..."}'
```

### `glow chat create`

```bash
glow chat create --body '\{...}'
```

### `glow chat update`

```bash
glow chat update --body '\{"chat_id": "...", ...}'
```

### `glow chat delete`

```bash
glow chat delete --body '\{"chat_id": "..."}'
```

### `glow chat list`

```bash
glow chat list
```

### `glow chat export`

```bash
glow chat export
```

### `glow chat draft`

```bash
glow chat draft --body '\{...}'
```

### `glow chat media`

```bash
glow chat <file|image|text|audio|video> <upload|download|create|chunk|status|finalize|discover|preview> [flags]
```
