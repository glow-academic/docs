# Attempt

## Commands

### `glow attempt`

```bash
glow attempt <action> [--body JSON]
```

### `glow attempt search`

```bash
glow attempt search
```

### `glow attempt get`

```bash
glow attempt get --body '\{"attempt_id": "..."}'
```

### `glow attempt create`

```bash
glow attempt create --body '\{...}'
```

### `glow attempt update`

```bash
glow attempt update --body '\{"attempt_id": "...", ...}'
```

### `glow attempt delete`

```bash
glow attempt delete --body '\{"attempt_id": "..."}'
```

### `glow attempt list`

```bash
glow attempt list
```

### `glow attempt export`

```bash
glow attempt export
```

### `glow attempt draft`

```bash
glow attempt draft --body '\{...}'
```

### `glow attempt media`

```bash
glow attempt <file|image|text|audio|video> <upload|download|create|chunk|status|finalize|discover|preview> [flags]
```
