# Record

Record provides the individual TA training history -- a single-profile view of the same dashboard metrics available at the institutional level. It is the admin-facing equivalent of drilling into one TA's performance across all simulations, rubrics, and scenarios.

## What is Record?

Record answers the question: "How is this specific TA doing?" It returns the full `DashboardBundleResponse` scoped to a single `target_profile_id`, including:

- Header metrics (total attempts, average score, completion percentage, first-attempt pass rate)
- Primary, secondary, and footer metric panels
- Rubric and parameter breakdowns (Communication Skills, Policy Knowledge, De-escalation)
- Simulation and scenario metadata
- Score thresholds and AI-generated insights
- The TA's profile information (name, email, role)
- Paginated attempt history

This is the view program coordinators use during one-on-one meetings to review a TA's progress, identify weak areas, and discuss improvement strategies.

## Quick Start

### CLI

```bash
# Get a specific TA's training record
glow record get --body '{"target_profile_id": "ta-profile-uuid"}'

# Get record with date range filter
glow record get --body '{"target_profile_id": "ta-profile-uuid", "start_date": "2025-01-01", "end_date": "2025-06-30"}'

# Search the TA's attempt history (paginated)
glow record search --body '{"target_profile_id": "ta-profile-uuid", "page": 1, "page_size": 20}'

# Export the TA's record as a ZIP
glow record export --body '{"target_profile_id": "ta-profile-uuid"}'
```

### API

```bash
# Get TA record
curl -X POST https://<your-instance>/v5/record/get \
  -H "X-Api-Key: <api-key>" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "target_profile_id": "ta-profile-uuid",
    "start_date": "2025-01-01",
    "end_date": "2025-06-30"
  }'

# Search TA attempt history
curl -X POST https://<your-instance>/v5/record/search \
  -H "X-Api-Key: <api-key>" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "target_profile_id": "ta-profile-uuid",
    "sort_by": "date",
    "sort_order": "desc",
    "page": 1,
    "page_size": 10
  }'
```

## Filtering

| Filter | Field | Description |
|---|---|---|
| Target TA (required) | `target_profile_id` | UUID of the TA to view |
| Date range | `start_date`, `end_date` | Scope to a semester or custom window |
| Cohorts | `cohort_ids` | Filter by training cohort |
| Departments | `department_ids` | Filter by academic department |
| Simulations | `simulation_ids` | Filter by specific simulations |
| Rubric picker | `rubric_ids`, `rubric_search` | Drill into rubric breakdowns |
| Scenario picker | `scenario_ids`, `scenario_search` | Filter by scenarios |
| Parameter picker | `parameter_ids`, `parameter_search` | Filter by parameters |

### History-specific filters

When searching history via `/record/search`:

| Filter | Field | Description |
|---|---|---|
| Practice only | `practice` | Show only practice attempts |
| Scenarios | `scenario_ids` | Filter by scenario |
| Infinite mode | `infinite_mode` | Filter by infinite mode |
| Include archived | `show_archived` | Include archived attempts |
| Simulation search | `simulation_search` | Text search by simulation |
| Scenario search | `scenario_search` | Text search by scenario |

## Understanding the Response

The `/record/get` response is a `DashboardBundleResponse` scoped to one TA:

- **`profile_name`** -- The TA's display name
- **`profile_emails`** -- The TA's email addresses
- **`profile_primary_email`** -- Primary email address
- **`profile_role`** -- The TA's role
- **`header_metrics`** -- Total attempts, average score, completion percentage, first-attempt pass rate
- **`primary_metrics`** / **`secondary_metrics`** / **`footer_metrics`** -- Detailed metric panels
- **`rubrics`**, **`parameters`**, **`scenarios`**, **`simulations`** -- Breakdown metadata
- **`thresholds`** -- Score threshold configuration
- **`insights`** -- AI-generated insights about this TA's performance
- **`history`** -- Inline paginated attempt history

## Exporting a TA Record

```bash
curl -X POST https://<your-instance>/v5/record/export \
  -H "X-Api-Key: <api-key>" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"target_profile_id": "ta-profile-uuid"}'
```

The export returns a denormalized ZIP with `content` (base64-encoded), `file_name`, `mime_type`, and `row_count`. This is useful for FERPA-compliant data requests or sharing a TA's progress report.
