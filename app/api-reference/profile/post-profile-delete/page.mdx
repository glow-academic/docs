# `POST` `/profile/delete`

Delete Profile

Bulk delete profiles — composable infra architecture.

## Request Body (`DeleteProfileApiRequest`)

| Field | Type | Required | Description |
|---|---|---|---|
| `profile_ids` | `string`[] | Yes | UUIDs of profiles to delete |
| `idempotency_key` | `string` | No | Operation key for ack — confirms or rejects a dormant delete |
| `accept` | `boolean` | No | Accept (confirm) or reject dormant state. Only meaningful with idempotency_key |

## Response (`DeleteProfileApiResponse`)

| Field | Type | Required | Description |
|---|---|---|---|
| `results` | [`DeleteProfileResult`](/api-reference/profile/types#deleteprofileresult)[] | Yes | Per-item deletion results |
| `idempotency_key` | `string` | No | Idempotency key echoed back for client correlation |
