# `POST` `/attempt/chat_silence`

Chat Silence

End a voice session for an attempt chat.

## Request Body (`ChatSilenceRequest`)

| Field | Type | Required | Description |
|---|---|---|---|
| `chat_id` | `string` | Yes | — |
| `idempotency_key` | `string` | No | — |
| `soft` | `boolean` | No | — |
| `accept` | `boolean` | No | — |

## Response (`AudioStopInternalResult`)

| Field | Type | Required | Description |
|---|---|---|---|
| `chat_id` | `string` | Yes | — |
| `stopped` | `boolean` | No | — |
| `idempotency_key` | `string` | No | — |
