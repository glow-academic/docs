# `POST` `/attempt/record/export`

Export Record

Export record data (dashboard for one profile) as a clean, denormalized ZIP.

## Request Body (`ExportRecordApiRequest`)

| Field | Type | Required | Description |
|---|---|---|---|
| `target_profile_id` | `string` | Yes | — |

## Response (`ExportRecordApiResponse`)

| Field | Type | Required | Description |
|---|---|---|---|
| `content` | `string` | Yes | Base64-encoded file content |
| `file_name` | `string` | Yes | Suggested download file name |
| `mime_type` | `string` | Yes | MIME type of the export file |
| `row_count` | `integer` | Yes | Number of rows in the export |
