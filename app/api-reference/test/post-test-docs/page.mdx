# `POST` `/test/docs`

Get Test Docs Endpoint

Get composed documentation for the test analytics.

## Request Body (`DocsApiRequest`)

| Field | Type | Required | Description |
|---|---|---|---|
| `entity_id` | `string` | No | — |

| `api_operations` | [`OperationInfo`](/api-reference/test/types#operationinfo)[] | Yes | API operation documentation |
| `page_metadata` | [`DocsApiResponse`](/api-reference/test/types#docsapiresponse) | No | Page-level metadata from docs API |
