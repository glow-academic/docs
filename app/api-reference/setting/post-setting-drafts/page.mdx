# `POST` `/setting/drafts`

Get Setting Drafts

List setting drafts owned by the current profile.

## Request Body (`GetSettingDraftsApiRequest`)

| Field | Type | Required | Description |
|---|---|---|---|
| `search` | `string` | No | Name search (ILIKE substring) |
| `date_from` | `string` | No | Start date filter |
| `date_to` | `string` | No | End date filter |
| `page_limit` | `integer` | No | Maximum items per page |
| `page_offset` | `integer` | No | Offset for pagination |
| `snapshot_key` | `string` | No | Cache snapshot key for consistent reads across related requests |

## Response (`GetSettingDraftsApiResponse`)

| Field | Type | Required | Description |
|---|---|---|---|
| `entries` | [`GetSettingDraftResponse`](/api-reference/setting/types#getsettingdraftresponse)[] | No | List of setting draft entries |
