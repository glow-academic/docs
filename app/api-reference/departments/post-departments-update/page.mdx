# `POST` `/departments/update`

Update Department

Update departments using composable infra architecture.

## Request Body (`UpdateDepartmentApiRequest`)

| Field | Type | Required | Description |
|---|---|---|---|
| `departments` | [`UpdateDepartmentItem`](/api-reference/departments/types#updatedepartmentitem)[] | Yes | List of departments to update |

## Response (`UpdateDepartmentApiResponse-Output`)

| Field | Type | Required | Description |
|---|---|---|---|
| `results` | [`DepartmentResultItem`](/api-reference/departments/types#departmentresultitem)[] | Yes | Per-item update results |
