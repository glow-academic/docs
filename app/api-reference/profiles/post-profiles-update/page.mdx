# `POST` `/profiles/update`

Update Profile

Update profiles using composable infra architecture.

## Request Body (`UpdateProfileApiRequest`)

| Field | Type | Required | Description |
|---|---|---|---|
| `profiles` | [`UpdateProfileItem`](/api-reference/profiles/types#updateprofileitem)[] | Yes | List of profiles to update |

## Response (`UpdateProfileApiResponse-Output`)

| Field | Type | Required | Description |
|---|---|---|---|
| `results` | [`ProfileResultItem`](/api-reference/profiles/types#profileresultitem)[] | Yes | Per-item update results |
