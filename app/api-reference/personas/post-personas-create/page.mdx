Create Persona

Create personas using composable infra architecture.

| Field | Type | Required | Description |
|---|---|---|---|
| `personas` | [`CreatePersonaItem`](/api-reference/personas/types#createpersonaitem)[] | Yes | List of persona items to create |

## Response (`CreatePersonaApiResponse-Output`)

| Field | Type | Required | Description |
|---|---|---|---|
| `results` | [`PersonaResultItem`](/api-reference/personas/types#personaresultitem)[] | Yes | Per-persona creation results |
