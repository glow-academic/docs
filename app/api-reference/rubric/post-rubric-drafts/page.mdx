# `POST` `/rubric/drafts`

Get Rubric Drafts

List rubric drafts owned by the current profile.

## Request Body (`GetRubricDraftsApiRequest`)

| Field | Type | Required | Description |
|---|---|---|---|
| `search` | `string` | No | Name search (ILIKE substring) |
| `date_from` | `string` | No | Start date filter |
| `date_to` | `string` | No | End date filter |
| `page_limit` | `integer` | No | Maximum items per page |
| `page_offset` | `integer` | No | Offset for pagination |

## Response (`GetRubricDraftsApiResponse`)

| Field | Type | Required | Description |
|---|---|---|---|
| `entries` | [`GetRubricDraftResponse`](/api-reference/rubric/types#getrubricdraftresponse)[] | No | List of rubric draft entries |
