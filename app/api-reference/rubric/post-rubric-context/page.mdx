# `POST` `/rubric/context`

Get Rubric Context

Get page context for the rubric artifact.

Returns docs + profile identity + evaluated permissions in a single call.
Superset of /docs — clients can migrate from /docs to /context incrementally.

## Request Body (`DocsApiRequest`)

| Field | Type | Required | Description |
|---|---|---|---|
| `entity_id` | `string` | No | — |
| `snapshot_key` | `string` | No | — |
| `schema` | `boolean` | No | If true, include MCP/tooling schema metadata (artifact, entries, resources, permission_docs, api_operations). Defaults to false for lean page-bootstrap responses. |

## Response (`ComposedContextResponse`)

| Field | Type | Required | Description |
|---|---|---|---|
| `name` | `string` | Yes | Artifact name |
| `type` | `string` | Yes | Artifact type identifier |
| `description` | `string` | Yes | Human-readable description |
| `artifact` | [`DocsResponse`](/api-reference/rubric/types#docsresponse) | No | Artifact tool documentation (None unless schema=true) |
| `entries` | [`DocsResponse`](/api-reference/rubric/types#docsresponse)[] | No | Entry documentation list (None unless schema=true) |
| `resources` | [`DocsResponse`](/api-reference/rubric/types#docsresponse)[] | No | Resource documentation list (None unless schema=true) |
| `permission_docs` | [`OperationInfo`](/api-reference/rubric/types#operationinfo)[] | No | Permission function signatures for MCP/dev tooling (None unless schema=true) |
| `api_operations` | [`OperationInfo`](/api-reference/rubric/types#operationinfo)[] | No | API operation documentation (None unless schema=true) |
| `page_metadata` | [`DocsApiResponse`](/api-reference/rubric/types#docsapiresponse) | No | Page-level metadata |
| `prompts` | [`OperationPrompts`](/api-reference/rubric/types#operationprompts) | No | Starter prompts keyed by operation |
| `profile` | [`ProfileSummary`](/api-reference/rubric/types#profilesummary) | Yes | Caller identity from JWT |
| `caller_permissions` | [`CallerPermissions`](/api-reference/rubric/types#callerpermissions) | Yes | Evaluated permissions for this caller |
