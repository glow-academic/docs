# `duplicate_scenario`

Duplicate a scenario — composable infra architecture.

## Parameters

| Name | Type | Required | Description |
|---|---|---|---|
| `scenario_id` | `string` | Yes | UUID of the scenario to duplicate |

## Example

```json
{
  "name": "duplicate_scenario",
  "arguments": {
    "scenario_id": "<scenario_id>"
  }
}
```
